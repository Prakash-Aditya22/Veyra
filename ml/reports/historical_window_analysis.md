# Historical-window analysis: does more STATS19 history help the blackspot forecast?

*Phase 2 research, 2026-10-14. The v2 production model is unchanged. All numbers come from
`historical_window_tables.md` and `historical_window_results.csv`, generated by
`ml/experiments/historical_windows.py` and `summarise_windows.py`. The frozen v2 spec is
`b9487674e4f1…`.*

**Short answer.** Yes, modestly and consistently, **through the years used to build the
predictors**. Predictors built from every year since 2015 (equal weights, or decayed with a
4-year half-life) beat v2's 3-year window in every development fold, population, road class
and region. The gain is +0.5 to +1.1 points of top-10% capture (CIs exclude zero) and 0.5–2.5%
lower Poisson deviance (1.6% on average over the three development folds). Excluding 2020–21 does
not improve the ranking, but excluding it from both predictors and training target fixes the
forecast *level* when the latest training target is COVID-depressed. Supplying more training
periods (stacking pairs) gave small and inconsistent changes. Shorter windows hurt. **The
production model is not changed.** The finding is recommended as a pre-registered change for
the next version, to be confirmed on the first untouched period.

> **Phase 3 corrections (2026-10-14).** No number in the result tables changed. Five statements
> were made precise after re-deriving them from the tables (`phase3_initial_audit.md` §2.A):
> - **Deviance.** "About 2.5% lower deviance" was the largest development fold, not the typical one.
> - **Bootstrap means.** The quoted paired differences are bootstrap means; the full-sample point differences are listed beside them.
> - **Stacking.** It was not "no gain": one development fold shows a small significant gain, and an exploratory fold shows a small significant loss.
> - **Decay vs equal weights.** These were never compared directly, so "marginally better" is replaced by "indistinguishable".
> - **Calibration.** The 0.77 → 0.98 fix needs **both** COVID exclusions. Every calibration ratio is now Σpredicted / Σobserved.
>
> Section 1.1 separates the four experimental choices.

## 1. Question and design

Does using more historical STATS19 data improve the **prospective** blackspot
forecast? Or does older data, or the COVID-19 period, dilute it? v2 builds
predictors from the 3 most recent years and trains on one (history → target)
pair. Two different "history" choices are tested separately:

| Choice | What it controls | Options tested |
|---|---|---|
| **Predictor history** H(k) | which collision years build a segment's features at cutoff k | last 2 / 3 (v2) / 4 / 5 years; every year since 2015; last 3 non-COVID years; exponential decay with half-life 1, 2 or 4 years |
| **Training pairs** T(c) | which (history → 2-year target) pairs, all ending by the cutoff c, fit the model parameters | most recent pair (v2); all feasible pairs stacked; most recent pair whose **target** avoids 2020–21 |

Everything else is held fixed:
- the frozen v2 LightGBM hyperparameters and the same 45 inference features;
- the same 1,827,550 segments and the same two-year adjusted-KSI target;
- the same tie-aware capture metric;
- the same 50 km block bootstrap, paired across strategies.

Count features from windows that are not 3 contiguous unweighted years are rescaled to a
"3-year-equivalent" (weighted sum × 3 / Σ weights). The meaning of a feature then does
not change with the window, and the reference configuration reproduces v2 bit for bit
(`test_windows.py::test_reference_reproduces_v2_exactly`). A year after the cutoff can
never enter the features (`History.years_weights` and an assertion in `windows.frame`;
tested).

Roles of the cutoffs were fixed before running:

| Cutoff | Test target | Role |
|---|---|---|
| 2019, 2020, 2021 | 2020–21, 2021–22, 2022–23 | **development**: conclusions; the decay half-life is chosen on 2019–2020 only, and 2021 checks it |
| 2022, 2023 | 2023–24, 2024–25 | **exploratory**: these targets were already examined in v2 and are used for robustness only, never to choose |
| 2025 | 2026–27 (unobserved) | ranking sensitivity only (`ranking_stability.md`) |

Data begin in 2015, so some strategies are infeasible at early cutoffs: 4- and 5-year
windows need 2014/2013 data for the 2019 training pair. Comparisons with the reference
therefore use only the folds where both are defined (`historical_window_tables.md`,
"Development summary"). At the 2019 cutoff no COVID year enters any window and only one
training pair is feasible, so the COVID and stacking strategies reproduce the reference
exactly. That is a built-in consistency check.

### 1.1 Four separate choices, and which experiment answers which (added in Phase 3)

Each strategy changes one choice and holds the rest at the v2 reference (last 3 years, equal
weights, one training pair, no exclusion). The **baseline is always the reference** on the same
cutoff and segments. The **metric is top-10% capture** of the 2-year adjusted-KSI target over all
1,827,550 segments, as a paired difference in points with a 200-resample 50 km block-bootstrap
95% CI, plus Poisson deviance relative to the reference. In the table below, "point" is the
full-sample difference from `historical_window_results.csv`; CIs are from
`historical_window_bootstrap.csv`.

| Choice | Strategies | Development result (cutoffs 2019 / 2020 / 2021) | Exploratory (2022 / 2023) | Supported conclusion |
|---|---|---|---|---|
| **1. Years used to build the predictors** | `A_all_single` (all years since 2015), `C_recent2/4/5_single` | all years: point +0.55 / +0.80 / +1.06, every CI excludes 0; deviance −0.5% / −1.8% / −2.5%. 2 years: −0.73 / −0.54 / −0.76 (CIs exclude 0). 4 years: — / +0.37 / +0.40; 5 years: — / — / +0.74 | all years +1.17 / +1.40, deviance −2.4% / −2.6% | **More predictor years help**, and the ordering 2 < 3 < 4 < 5 < all holds wherever the windows are defined |
| **2. Number of training periods supplied to the model** | `A_recent3_stacked` (every feasible history → target pair stacked; predictors stay 3-year) | 0 (only one pair feasible) / +0.05 [−0.14, 0.15] / **+0.22 [0.05, 0.44]**; deviance 0 / −0.3% / −0.8% (CIs exclude 0) | +0.20 [−0.02, 0.33] / −0.01 [−0.11, 0.20]; deviance **+0.3% (worse; CI excludes 0)** / +0.0% | **Small and inconsistent.** At 2020–21, stacking mixes pre-COVID targets into a COVID-depressed training target, so part of its gain may be a level effect (compare choice 3). Its benefit **on top of full-history predictors was not tested** (no "all years + stacked" strategy was run) |
| **3. Years excluded (2020–21)** | from predictors `B_nocovid3_single`; from the training target `B_recent3_noncovidpair`; both `B_nocovid3_noncovidpair` | capture CIs include 0 in every fold for all three. Calibration at 2021 (Σpred/Σobs): reference 0.77, predictors only 0.86, target only 0.88, **both 0.98** | capture CIs include 0 | **No ranking benefit; a level (calibration) benefit when the latest training target is COVID-affected**, mainly when both exclusions are combined |
| **4. Equal vs recency-weighted years** | `A_all_single` (equal) vs `D_decay_h1/h2/h4_single` (same years, half-life 1, 2, 4 years) | h chosen on 2019–20 deviance by the pre-declared rule: h = 4 (0.12761) < equal weights (0.12777) < h = 2 < h = 1. h = 4 minus equal weights, top 10%: −0.12 / +0.12 / +0.23 points; deviance lower by 0.07–0.18% of the reference | +0.23 / +0.03 | **Indistinguishable on this evidence.** No paired decay-vs-equal CI was computed, the differences are a fifth of the choice-1 effect, and h = 4 is the edge of the grid tested. Old crashes should be discounted little, if at all |

So the two statements "more history helps" and "more training periods give no clear
benefit" are **not in conflict**. They are answers to choices 1 and 2. The gain comes from what
a segment's predictors remember (choice 1), not from fitting the model on more periods (choice 2).

## 2. COVID-era mobility and reporting (context, local data)

`historical_window_context.csv`. The traffic index is vehicle-km on major-road DfT count
points present in every year 2015–2025 (a balanced panel, so it is not affected by
changes in which points were counted).

| Year | Major-road traffic (2019 = 100) | Collisions | Adjusted KSI | Reported KSI | Adjusted ÷ reported | Adjusted KSI per traffic index point |
|---|---|---|---|---|---|---|
| 2015 | 94.8 | 140,056 | 32,176 | 23,811 | 1.351 | 339 |
| 2018 | 98.8 | 122,635 | 30,643 | 27,058 | 1.132 | 310 |
| 2019 | 100.0 | 117,536 | 29,747 | 27,125 | 1.097 | 298 |
| **2020** | **75.8** | 91,199 | 23,217 | 21,562 | 1.077 | 306 |
| **2021** | **85.9** | 101,087 | 26,397 | 24,921 | 1.059 | 307 |
| 2022 | 94.8 | 106,004 | 28,926 | 27,531 | 1.051 | 305 |
| 2025 | 100.2 | 101,525 | 29,918 | 29,296 | 1.021 | 299 |

- **Mobility.** Major-road traffic fell 24% in 2020 and was still 14% down in 2021. Collisions and KSI fell by similar proportions, so **KSI per unit of traffic stayed flat** (298 → 306 → 307). COVID years have fewer crashes but say much the same about **where** crashes happen. That is why removing them helps the forecast level more than the ranking (below).
- **Reporting.** Reported KSI understates the injury-based standard by 35% in 2015 and 2% in 2025, as forces moved to CRASH/COPA. Every window here uses **DfT severity-adjusted** KSI for both features and target. A long window therefore does not mix 2015's under-recording with 2025's recording. With raw reported KSI, older years would look systematically safer, and longer windows would be biased.

### 3.4 Calibration and COVID

Excluding COVID years mainly fixes the forecast **level** when a fold's training target is
COVID-depressed. All ratios here are Σpredicted / Σobserved. At the 2021 cutoff (trained on a 2020–21
target, tested on 2022–23), the reference forecast 0.77 of what happened overall, and 0.77 in
its top decile. With **both** exclusions (training pair 2015–17 → 2018–19; test predictors
2017–19, skipping 2020–21) the ratio is 0.98 overall and 0.99 in the top decile. Either
exclusion alone recovers only part of the gap: 0.88 (training target only) and 0.86
(predictors only). Ranking barely moves, because COVID years still locate crashes correctly
(§2):
- **on all segments:** top-10% CIs include zero in every fold;
- **on roads without recent crashes:** a gain of +0.7 to +1.5 at 2020–21.

At the exploratory 2023 cutoff, whose training target 2022–23 is post-COVID, the exclusion
is neutral or slightly worse.

## 4. Answers

1. **Does more history help?** Yes, modestly and consistently, when "history" means the years behind the **predictors**. Predictors from every year since 2015 (or exponentially decayed with a 4-year half-life) improve deviance and top-5/10/20% capture in all three development folds, in every population tested, in all 11 regions and in every road class. The gain is larger at later cutoffs (+0.55 → +0.80 → +1.06 top-10% points with 5, 6 and 7 years of history), and both exploratory cutoffs agree. Because the number of available years rises with the cutoff, this trend is confounded with the fold and is suggestive only. Shorter windows (2 years) are worse everywhere.
2. **Should 2020–21 be excluded?** Not from the predictors' ranking information: excluding them leaves capture unchanged (CIs include zero) and discards real location information. Excluding them from **both the predictors and the training target** fixes level calibration when the only recent target is COVID-affected (0.77 → 0.98 at the 2021 cutoff; each exclusion alone reaches 0.86–0.88). That matters for forecasts made in 2021–22, not for the production model, whose training target (2024–25) is post-COVID.
3. **Is recency weighting better than equal weights?** Not demonstrably. Decay with h=4 (selected on 2019–2020 by the pre-declared rule) and equal weights differ by −0.12 to +0.23 top-10% points across folds, with no paired test of the two. Shorter half-lives (1, 2) were worse on the selection folds, and h=4 was the slowest decay tested. Old crashes should be discounted little, if at all.
4. **Does training on more periods help?** Not clearly. Stacking 2–5 training pairs with 3-year predictors changed top-10% capture by −0.01 to +0.22 points, significant only at 2021. It improved deviance at 2020–21 and worsened it at 2022, at 1.7–3.7× the fitting cost. Whether stacking adds anything once the predictors use all years was not tested.
5. **Is the gain uniform?** No. It is concentrated on roads without recent crashes, on unclassified and C roads, and outside London.

## 5. Recommendation

- **The v2 production model is not changed.** The protocol forbids changing it after the holdout was examined, and these results do not overturn the v2 model; they refine it.
- **For the next version (v3), pre-register** "predictors from all available years with a 4-year half-life decay (or equal weights)" as the history rule, with the frozen v2 LightGBM otherwise unchanged. In the folds tested the gain was +0.4 to +1.5 points of top-10% capture and 0.5–2.6% lower deviance, growing with the number of years available. With 10+ years by the next cutoff, the upper end is the more likely.
- **Confirm it on the first untouched period:** the 2026–27 outcomes when DfT publishes them (2027 data in autumn 2028). The 2024–25 period cannot serve as a fresh test, because it was already examined.
- **Calibration safeguard:** when the most recent training target is affected by a shock (as 2020–21 was), use the most recent unaffected training pair or rescale the level. Report the forecast level with that caveat.
- **Do not** drop 2015–2019 data as "obsolete", and do not drop 2020–21 from predictors. Stacking training pairs is not recommended on this evidence: its effect was small and inconsistent and it costs 2–4× the compute. If v3 wants to test it, pre-register it **together with** full-history predictors, the combination that was not run here.

## 6. Limitations

- Three development folds, and two of them have COVID-affected targets. That is the strongest design the 2015 data start allows. Longer windows are infeasible at early cutoffs, so their comparisons rest on 1–2 folds.
- Every strategy uses the frozen v2 hyperparameters (tuned for the 3-year window). Retuning per window might change the margins slightly. It was not done, to keep only the window varying.
- Bootstrap CIs resample 50 km blocks. They capture spatial dependence but not dependence between folds (folds share years).
- The 2022–2023 cutoffs reuse targets already examined in v2, so they are robustness evidence only.
- The road network is a 2026 snapshot (`data_quality.md` §7). Very old history on roads that changed since then may be misassigned. That effect, < 0.5% of crashes, would bias against long windows, not for them.
